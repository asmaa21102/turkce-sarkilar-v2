# Türkçe Şarkılar — v2

A music player app in Flutter.

Version 2 of [music](https://github.com/asmaa21102/music), rebuilt with Flutter 3 and Material 3.

**Try it:** https://asmaa21102.github.io/live/phone.html?app=turkce-sarkilar (runs in the browser, in a phone frame)

## Features

- A library of 12 tracks with search, makam filters, sorting, favourites and recently played
- Mini player and a full now-playing screen with up next, repeat, shuffle and a seek bar
- The tracks are original demo tunes generated inside the app (a plucked-string sound in Hicaz, Uşşak,
  Rast and other makams with a darbuka rhythm) — no copyrighted songs

## Run

```bash
flutter pub get
flutter run -d chrome      # or any connected device
flutter test
```
